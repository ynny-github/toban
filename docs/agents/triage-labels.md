# Triage Labels

スキルは 5 つの triage の役割で話す。このファイルは、その役割をこのリポジトリの Issue tracker で実際に使うラベルの文字列に対応させる。

| mattpocock/skills のラベル | このリポジトリのラベル | 意味                                         |
| -------------------------- | ---------------------- | -------------------------------------------- |
| `needs-triage`             | `needs-triage`         | メンテナが評価する必要がある                 |
| `needs-info`               | `needs-info`           | 報告者からの追加の情報を待っている           |
| `ready-for-agent`          | `ready-for-agent`      | 仕様が固まり、AFK のエージェントが着手できる |
| `ready-for-human`          | `ready-for-human`      | 人が実装する必要がある                       |
| `wontfix`                  | `wontfix`              | 対応しない                                   |

スキルが役割を口にしたら（例:「AFK-ready の triage ラベルを付ける」）、この表の対応するラベルを使う。

実際に使っている名前に合わせて、「このリポジトリのラベル」の列を書き換えてよい。
